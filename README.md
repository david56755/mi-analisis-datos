# mi-analisis-datos

Hola, soy David. Estoy aprendiendo a ser analista de datos.

## Qué tipo de analista quiero ser
Quiero ayudar a negocios pequeños (talleres, salones, tiendas) a tomar
mejores decisiones con sus propios datos: saber qué mes ganan más,
en qué gastan de más y quiénes son sus mejores clientes.

Ya he trabajado con negocios así: participé en apps para un taller
mecánico y para un salón de uñas, y ahora quiero aprender a analizar
los datos que esas apps generan.

## Qué estoy aprendiendo
- Excel y Google Sheets
- SQL
- Python (pandas)
- Estadística
- Power BI y Looker Studio
